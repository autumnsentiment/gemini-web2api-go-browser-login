New API 在线生图工作台 - 在线 AI 图像生成

New API 在线生图工作台是一个基于 OpenAI gpt-image-2 模型的在线 AI 图像生成应用。 支持流式 SSE 生成进度、渐进式部分预览图、思维链折叠展示、角色卡一致性、提示词收藏与增强、 种子控制、本地 IndexedDB 图库、多会话管理、键盘快捷键、失败自动重试。 所有生成历史与图库数据完全保存在浏览器本地，不会上传第三方服务器，保护隐私。

核心功能

  • 文生图：直接输入提示词生成高质量图像
  • 图生图：上传参考图加提示词生成变体
  • 角色卡：保持人物在多次生成中样貌一致
  • 提示词增强：用 LLM 改写提示词以贴合 gpt-image-2 习惯
  • 种子控制：同提示词不同种子获得不同变体
  • 提示词收藏：常用提示词一键复用
